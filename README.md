# weirdcrow.com

The Weird Crow website, published with GitHub Pages.

- `/` home
- `/karasuke/` Karasuke (App Store Marketing URL)
- `/karasuke/support/` Support URL
- `/karasuke/privacy/` Privacy Policy URL

Plain HTML and CSS, no build step. Edit a page, commit and push; GitHub Pages republishes it in a minute or two.
